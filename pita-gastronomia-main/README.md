# Pita Gastronomia — Site

Projeto pronto para publicação via GitHub + Vercel.

## Como publicar na Vercel

1. Crie um repositório no GitHub chamado `pita-gastronomia`.
2. Envie todos os arquivos desta pasta para o repositório.
3. Acesse https://vercel.com
4. Clique em **Add New Project**.
5. Importe o repositório `pita-gastronomia`.
6. Framework Preset: **Other**.
7. Build Command: deixe vazio.
8. Output Directory: deixe vazio.
9. Clique em **Deploy**.

## Domínio

Depois do deploy:
1. Vá em Project Settings > Domains.
2. Adicione o domínio desejado.
3. Siga as instruções de DNS da Vercel.
