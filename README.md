Pita Gastronomia — Site
Projeto pronto para publicação via GitHub + Vercel.
Como publicar na Vercel
Crie um repositório no GitHub chamado `pita-gastronomia`.
Envie todos os arquivos desta pasta para o repositório.
Acesse https://vercel.com
Clique em Add New Project.
Importe o repositório `pita-gastronomia`.
Framework Preset: Other.
Build Command: deixe vazio.
Output Directory: deixe vazio.
Clique em Deploy.
Domínio
Depois do deploy:
Vá em Project Settings > Domains.
Adicione o domínio desejado.
Siga as instruções de DNS da Vercel.
